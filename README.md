# AI Readiness Simple Funnel

Simple static website using PayPal buttons.

- index.html → Main $7 offer page
- upsell.html → Post-purchase upsell page ($49 and $479)

## How to use
1. Create 3 PayPal "Buy Now" buttons ($7, $49, $479)
2. Paste each button's HTML code into the correct placeholder
3. Set the Success URL on the $7 button to point to `upsell.html`
4. Deploy with GitHub Pages or Railway
